# 📝ConsoleNoteApp

A simple console-based note-taking application written in Java. It allows you to create, delete, and view notes directly from the terminal.

Features
· 📝 Create a note – add a new note with a title and content.
· 🗑️ Delete a note – remove an existing note by its ID or title.
· 📋 Show all notes – display a list of all saved notes.

How to Run
1. Ensure you have Java 8 or higher installed.
2. Clone the repository or download the source code.
3. Open the project in IntelliJ IDEA (or any Java IDE).
4. Run the Main class.
Alternatively, compile and run from the command line:
```bash
javac *.java
java Main
```

Notes are stored in memory only (no database) and will be lost when the application exits.
